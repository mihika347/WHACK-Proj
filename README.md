# FastForward

## UI demo

Open [`ui/index.html`](ui/index.html) in a browser. The page uses plain HTML, CSS, and JavaScript and runs without a build or backend.

1. Open **Performance Evaluation** on the pipeline.
2. Inspect the selected candidate's Python diff and demo evidence. **Results** also lets you inspect the candidate filtered for slower performance.
3. Choose **Approve change** or **Reject change** to update the **Approval queue**. Select the candidate in the queue to revisit or change your decision.

Timing and correctness figures are illustrative. Decisions are scoped to the browser tab's session.
