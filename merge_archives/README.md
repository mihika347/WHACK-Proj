# Preserved pre-merge generated datasets

The ZIP archives preserve the exact tracked `original.py`, `output/`, `reports/`, `tests/`, and `examples/failure_demo/reports/` trees from both merge parents:

- `main-9cb26ee-generated.zip`: main's original baseline, candidates, measurements, and inputs.
- `Ui_NAV-384282a-generated.zip`: Ui_NAV's original baseline, candidates, measurements, and inputs.
